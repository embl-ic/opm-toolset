Fiji plugin

OPM Toolset manual

The OPM Toolset deskews oblique plane microscopy data in Fiji - while the microscope is still writing it, or afterwards over a folder - and opens the results again for browsing and export.

Chapters

  • Live Deskew - deskew an acquisition as it is written, with a worked two-part example: a bead acquisition to calibrate the two camera halves, then the time lapse. Includes the background on why deskewing is needed, the geometry and the file formats, which apply to every deskew command.
    Offline copy (single file)

More chapters - Deskew Batch, the OPM Data Viewer, deconvolution - will be added here. Until then, each command's Help button describes its own dialog, and the geometry and format sections of the Live Deskew chapter apply to all of them.

Installing the plugin

  1. Copy OPM_Toolset-<version>.jar into Fiji/plugins.
  2. Restart Fiji. The commands appear under Plugins ▸ OPM Toolset.
  3. For GPU acceleration, install CLIJ2 from the Fiji updater (the toolset falls back to the CPU when no OpenCL device is available).
  4. For the OME-Zarr reader, Fiji needs n5-zarr 2.0.1 or newer.

The commands

MenuWhat it does
Deskew ImageDeskew the open volume, with a preview.
Deskew LiveDeskew an acquisition while it is being written, over TCP/IP or by watching a folder. Chapter.
Batch Processing ▸ DeskewThe same, over a folder that is complete.
Batch Processing ▸ Generate Projection ImageProjections and projection movies of a folder of volumes, deskewing raw ones first, with the same channel options as Deskew.
Batch Processing ▸ Channel OperationSplit, flip, align and recombine the camera halves of deskewed results. An OME-Zarr only has its alignment metadata replaced.
Batch Processing ▸ DeconvolutionRichardson-Lucy, and a PSF from a bead image.
Batch Processing ▸ Format ConversionTIFF volumes, TIFF results and OME-Zarr datasets to deflated TIFF or OME-Zarr, without deskewing. A single file can be named instead of a folder.
Batch Processing ▸ Terminate…Stop a run that is already going.
OPM Data ViewerOpen OME-Zarr and TIFF results, crop regions, follow a run in progress.
Utilities ▸ Channel AlignmentMeasure the rigid 2-D overlay of the camera halves from beads. Section.
Utilities ▸ …Projection, transform, permutation, OME-Zarr region export, environment report.

Where this comes from

The toolset is developed at the EMBL Imaging Centre for its in-house OPM. Source, issues and releases: github.com/embl-ic/opm-toolset.
